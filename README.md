### 05.10.2026 — Юніт 3: система здоров'я

**Що зроблено:** 
Налаштовано систему здоров'я персонажа, тригерні аптечки та зони шкоди з таймером невразливості. Реалізовано посилену аптечку (+2 HP) та зону повільного лікування.

**Що не вийшло або забрало найбільше часу:** 
Найбільше часу пішло на правильне налаштування компонента Box Collider 2D з галочкою Is Trigger, перевірку наявності потрібних компонентів фізики та виправлення прив'язок вводу (Move Action) у PlayerController.

**Що зрозумів про тригери, public і private:** 
Колайдер-тригер (Is Trigger) реєструє факт входження об'єктів без фізичного зіткнення. Модифікатор private обмежує доступ до змінної currentHealth з інших скриптів, а public-властивість health надає безпечний доступ лише для читання.

**Яке значення Time Invincible обрав і для якого гравця:** 
Обрано значення 2.0 секунди. Це дає казуальному гравцеві достатньо часу для реакції та виходу із зони шкоди без швидкої втрати всіх HP.
